Conclusión

Para el proyecto final usaríamos Bootstrap como base y conservaríamos un pequeño kit propio para los detalles de marca. El rendimiento medido fue prácticamente igual, pero Bootstrap requirió muchas menos líneas de CSS y facilita mantener una presentación responsive. Si el diseño necesitara componentes muy particulares, el kit propio daría más control.

Nota: no se proporcionaron URLs públicas. Por eso se compararon las copias locales de ambas versiones, no sus publicaciones.
